## 🛠 ТЕХНИЧЕСКИЙ_СТЕК

Я специализируюсь на создании мобильных и веб-приложений с использованием современного стека:

* **Frontend & Mobile:** Dart, Flutter (основной фреймворк).
* **Backend:** Python, Java, Supabase (база данных).
* **AI Integration:** Интеграция AI-функций через Google AI Studio и Gemini.
* **Design:** Пиксель-арт в Aseprite для персонажей и интерфейсов.
